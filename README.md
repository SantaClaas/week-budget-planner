# Week Budget Planner

Give each activity (a class, a job, the gym) an hour budget per week or per day. Then put blocks of it on a Monday–Sunday week and resize them until every budget reads "All placed".

This repo starts as a handoff kit. The next step is building the app with SolidJS 2.0.

- [`prototype/week-budget-planner.html`](prototype/week-budget-planner.html): the working prototype. Open it in a browser and it saves to localStorage.
- [`docs/SPEC.md`](docs/SPEC.md): the behavior and design spec for the port, split by topic in [`docs/spec/`](docs/spec/), with the glossary.
- [`docs/design/m3-tokens.css`](docs/design/m3-tokens.css): the Material 3 Expressive design tokens.
- [`CLAUDE.md`](CLAUDE.md): context for Claude Code sessions.
- `.agents/skills/modern-web-guidance/`: Google Chrome's [Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance) skill for coding agents, installed with `pnpx modern-web-guidance@latest install`.
